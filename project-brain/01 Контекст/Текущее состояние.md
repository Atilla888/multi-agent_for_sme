- **M01–M07:** финальная регрессия **114/114**, без падений и пропусков; формальная ревалидация P3 на замороженном коммите `1cd69e3`.
- **M08:** общий runtime специалистов, типизированные решения, версионированные промпты и адаптер Gemini REST реализованы. Скриптовые кейсы — 142/142 (114 + 28). Живые кейсы с Gemini упали до ответа модели: `AUTHENTICATION`, затем HTTP 429. Полная live-приёмка не доказана.
- **С 05.11.2026** в коде есть провайдер **Claude** (`DEV_LLM_PROVIDER=claude`, модель по умолчанию в демо — `claude-opus-5-5`) и рабочий канал WhatsApp. Закрывает ли это гейт M08, в документах **не записано** — см. [[04 Работа/Расхождения источников]].
