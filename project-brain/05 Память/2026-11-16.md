# 2026-11-16 · Языки RU/KZ, светлая и тёмная тема, база в репозитории

## Контекст

Атилла попросил добавить казахский и русский языки интерфейса и переключатель светлой и тёмной темы («не каждый пользователь говорит по-английски»), переводить только интерфейс. Перед этим — вход без авторизации для локального просмотра, обновление Next.js и публикация этой базы на GitHub.

## Результат

- **Вход без авторизации для `npm run dev`** (`8f353c5`, PR #3): флаг `LOCAL_PREVIEW_NO_SIGN_IN=true` открывает все экраны как «Demo owner» на примерах данных; production-сборка его игнорирует.
- **Next.js 16.4.0 → 16.4.6** (`4a45ade`, PR #3): закрыты GHSA-2464-fhr4-w9xw и GHSA-673q-mjm6-r5xr (удалённое выполнение кода) и GHSA-p3m5-59mp-jv5r (DoS).
- **База в репозитории** (`026bcb3`): папка `project-brain/` теперь в `main`; текст очищен для публикации, локальные пути убраны, ссылки ведут на файлы на GitHub.
- **Языки и тема** (`bbbed3e`, слияние `dfc5f55`): next-intl 4.14.9 без языка в URL. Язык — cookie `lang`, иначе язык браузера, иначе английский. Переключатели языка и темы (Как в системе / Светлая / Тёмная) — в сайдбаре, в листе «Ещё» на телефоне, на странице входа и в чате клиента. Тема ставится на сервере (cookie `theme`), без мигания. Тексты — `frontend/src/i18n/messages/<область>.ts`, en/ru/kk рядом; около 1 300 сообщений. Пять параллельных исполнителей перевели экраны; общую часть (оболочка, статусы, вход, бизнес-списки) — основной исполнитель.

## Проверка

- `npm run lint`, `typecheck`, `test` (29 файлов, 365/365) и `build` проходят; после слияния в `main` — 365/365.
- Английский вывод экранов побайтно совпадает с прежним (исполнители сравнивали рендер до и после), кроме двух исправленных множественных форм: «1 conversation · 1 order», «1 message».
- Проверка каталога: одинаковые ключи и плейсхолдеры во всех языках, нет непереведённого английского, казахский не копия русского.
- 150 превью (`PREVIEW_LOCALE`, `PREVIEW_THEME`) и 120 скриншотов RU/KZ на 1440 и 390 px — без горизонтального переполнения. Остаток английского в RU/KZ — только содержимое записей (имена, сообщения, товары, документы, ID) и бренды.
- В работающем приложении: cookie `lang=ru` + `theme=dark` даёт `<html lang="ru" data-theme="dark">`; `Accept-Language: kk` даёт казахский.

## Решения и вопросы

- Переводится интерфейс; содержимое записей показывается как введено — решение Атиллы.
- Казахский — кириллица. Русский и казахский тексты написаны без носителя языка: нужна вычитка.
- Цвет аватара берётся из непереведённого имени (`colorKey`), чтобы человек не менял цвет при смене языка.
