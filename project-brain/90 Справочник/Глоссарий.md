## Состояния и ограничения

| Термин | Значение |
|---|---|
| **E02** | Утверждённое ограничение: мутация `update_order` заблокирована политикой (`BLOCKED_BY_APPROVED_POLICY`) |
| **`OUTCOME_UNKNOWN`** | Запись могла пройти. Нужна сверка; слепой повтор запрещён |
| **`MODEL_NOT_READY`** | Честный ответ прогноза, пока нет проверенной модели M13 |
| **TARGET** | Целевое поведение, только в дизайне; не реализовано |
| REAL / FIXTURE / UNAVAILABLE | Экран на живом API / на типизированных примерах / недоступен |
| LIVE / MOCK / SANDBOX | Режимы интеграции; запись конфигурации ≠ живой канал |
| READY ≠ published | Документ обработан, но не опубликован для поиска |
| ACTUAL / PREDICTED | Исторические данные / прогноз; сплошная и пунктирная линия |
| Known Failure | Известно, что эффекта не было; есть путь восстановления |
