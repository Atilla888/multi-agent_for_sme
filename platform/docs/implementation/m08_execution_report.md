## Implemented, not accepted as complete

`agents/contracts.py` defines strict `AgentDecision` values RESPOND/CALL_TOOL/CLARIFY/HANDOFF/ESCALATE/COMPLETE, semantic confidence HIGH/MEDIUM/LOW/UNKNOWN, bounded evidence refs, reason codes and normalized `AgentOutcome`. `agents/prompts.py` contains versioned DEVELOPMENT shared and Sales/Support/Analytics prompts. `agents/runtime.py` instantiates exactly the three approved specialists over the same Business Brain and M04 trusted ToolExecutor. The Brain supplies M06's minimal model projection; the model cannot set principal, business scope or role. Tool proposals are passed through the exact M04 schema/role/resource/tenant checks. A trusted `write_confirmed` request flag gates writes, and stable run+tool+argument operation keys prevent duplicated writes within a run. A successful write is summarized from the trusted ToolResult, overriding contradictory model prose. OUTCOME_UNKNOWN halts further write proposals. In-memory trace events capture context digest, decisions, tool results and terminal state; no durable M11/M12 checkpoint is claimed.

`agents/provider.py` defines an LLMProvider protocol with `invoke_structured`, `invoke_with_tools`, `model_info` and `usage_info`. Its Gemini REST adapter uses pinned `httpx==0.28.1`; no Google SDK was added. Native Gemini function calls are parsed as proposals, never auto-executed. Provider metadata normalizes model/version/request ID, tokens, cached tokens, latency, finish reason, tool-call count and retries; failures have bounded categories. The DEVELOPMENT default model is `gemini-3.8-flash` with temperature 0.2, top-p 0.95, max output 1024, timeout 20 seconds and one retry. The [official model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash) lists stable function calling, structured outputs and a sufficient context window; [official function-calling guidance](https://ai.google.dev/gemini-api/docs/function-calling) retains application-side execution. This is not the Final model freeze. Prompt/config hashes and versions are in `m08_prompt_model_registry.md`.
