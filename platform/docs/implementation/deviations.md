# Deviations and owner decisions

No frozen architecture, schema/domain meaning, ten-tool set, agent set, security boundary or research-treatment deviation was made in M01–M05. The approved `physical_schema.sql` remains byte-preserved; M05's Alembic `0004_staff_identity_lookup` adds only a least-privilege staff lookup function, without changing a frozen business table or granting runtime global `app_users` SELECT.

Controlled unresolved approved-policy branch: the sanitized handoff does not provide an E02 `update_order` editable-field/transition allowlist. The tool validates, authorizes and records a typed `POLICY_REJECTED`/`BLOCKED_BY_APPROVED_POLICY` outcome; it never mutates the order. Owner approval of exact editable fields/transitions is required before enabling the mutation branch. No release, cancellation, refund, compensation or payment semantics were invented.

Forecast pre-artifact behavior is intentionally `MODEL_NOT_READY`; no fake model or ForecastRun is created. A delivery reference without a configured adapter yields a typed dependency failure; an order without a reference yields explicit no data. These are truthful M04 boundaries, not domain redesign.

The M02 implementation note still applies: revision 0001 verifies the approved physical-schema SHA-256 before executing it. Trusted server code sets PostgreSQL's transaction-local tenant context. Runtime DB credentials remain server-only; M05 now additionally enforces current membership, object ownership, agent permission and tool permission. A generic runtime credential is not a substitute for application identity authorization.

The prior handoff's `HOLDOUT_CONTAMINATION_RISK` is not erased by implementation tests. Its independent research-data custody/review remains outside this checkpoint. No private Final/Pilot cases or benchmark oracle were used.

M07 keeps the approved Document/DocumentVersion/ObjectRecord/Embedding semantics. No legal retention period or physical purge is invented; revocation removes reader visibility while historical object/audit data remains.
